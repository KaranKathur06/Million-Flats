🛡

Honesty by design

AIView should distinguish verified facts, unavailable evidence, and untested claims. EXIF data can be modified, dimensions require reliable geometry or independent measurement, and lighting authenticity may require original frames and processing records.

Recommended MVP Architecture

Five-stage pipeline to establish verifiable visual provenance for real-estate digital assets.

STAGE 1
Capture
Start with one supported scanner workflow and document exactly which metadata and export formats it provides.
STAGE 2
Ingestion
Upload original export directly to controlled cloud storage, compute SHA-256 server-side, and preserve original as immutable evidence.
STAGE 3
Audit
Store signed manifest, timestamps, device details, available geolocation, and a tamper-evident event log.
STAGE 4
Review
Add independent scan-geometry checks and image-processing disclosure; report each result separately.
STAGE 5
Buyer Report
Show a QR-linked verification page with evidence provenance, scan date, file integrity status, and explicit limitations.
